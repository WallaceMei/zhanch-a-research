## 2. 继续研究的核心问题

上一版组合模拟默认使用：

```text
core_exposure = 60%
max_total_position_ratio = 75%
```

但新的真实仓位要求是：

```text
正常市场环境：满仓运行，目标 100% 仓位
不默认设置 75% 总仓位上限
只有大盘环境极差时才缩仓
```

因此，本次研究目标是：

1. 对 Rule D、deep_water、确认天数等条件进行精细化拆分。
2. 新增 100% 满仓复利组合模拟。
3. 比较保守 75% 模型与满仓模型的收益、回撤和替换效果。
4. 只做研究脚本，不写真实策略。

## 5. 大盘极差缩仓代理

只做研究，不写入真实策略。


极差市场初步定义：

```text
regime in ['bear', 'panic', 'extreme']
或 trend == 'down' 且 regime != 'bull'
```

## 8. 判断标准

精细化规则进入下一步的基本标准：

```text
sample_count 不能太少
win_rate 最好 >= 55%-60%
median_return_3d / median_return_5d 必须为正
max_loss 不能过大
top_gain_contribution_ratio 不能过高
```

满仓组合进入真实策略实验版的基本标准：

```text
satellite_profit 必须为正
max_drawdown_proxy 不能明显恶化
replacement 后 new_position_profit_after_buy 要明显好于 replaced_profit_after_sell
Full-A/B/C 至少有一个收益回撤比优于 Conservative-75
```
