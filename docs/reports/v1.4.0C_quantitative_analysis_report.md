## 3. 反过拟合与健壮性定量评估

从 `v14C_overfit_final_check.csv` 和成本敏感性数据中提取：

- **参数扰动稳定性**: **Fail**。小幅度改变晋级阈值/卫星利润等参数时，总收益在 24.34% ~ 67.81% 间剧烈波动，标准差高达 10.70%，被评定为 Unstable。
- **成本衰减 (1.5x / 2.0x 成本)**: **Pass**。总收益分别回撤 13.24% 和 26.50%，说明其收益并非由微弱的剥头皮毛利堆叠。
- **盈利集中度**: **Fail**。轮动策略 Top 3 盈利标的的利润贡献度 (profit_share) 达到 1.045 (>100%)。即：前 3 笔大肉交易掩盖了剩余所有交易的净亏损。

## 4. 收益结构与机制归因

### A. 晋级机制贡献 (Promotion Attribution)
- 晋级次数：16 次
- 晋级交易整体胜率：56.25%
- 晋级前（卫星段）盈亏：正向贡献
- **晋级后纯段盈亏：-108,974.12**
**定量结论**：晋级后持有段实际上是纯亏钱的，当前晋级逻辑并没有抓住趋势加速，反而大概率在高位接盘站岗。轮动机制的超额收益本质上来自于“把好股票选进了卫星并长拿了几天”，而绝非“晋级”这一动作。

### B. 亏损交易归因 (Loss Attribution)
- 亏损总金额：-987,687.28 (82笔)
- **快速亏损占比 (Fast Loss, ≤5天)**：56.03% 的笔数，和 **89.1% 的亏损金额 (-880,789.68)**。
**定量结论**：亏损结构极度恶劣。系统高频出现“买入即被套，并在极短时间内快速止损”的现象，入场点的短期动量或情绪极差。

---

## 5. 总结与量化建议

### 总体评级：不达标，切勿进入主线实盘。

**核心问题暴露**:
1. **盈利集中度畸高**: 策略的69%年化完全依赖少于5笔的“彩票型”大肉，常态交易处于失血状态。
2. **买点短线胜率极差**: 89%的亏损来源于买入5天内的快速止损，说明前置过滤 (Prefilter / Core Candidates) 无法有效识别次日溢价。
3. **晋级机制为伪命题**: 晋级后的持有期期望为负，并未吃到主升浪，反而拉低了总体资金使用效率。
4. **参数脆弱**: 一旦偏移现有的特定门槛（如卫星入选比例），系统就会坍塌。

**下一步改进建议 (纯量化方向)**:
1. **彻底重构选股入场特征**:
   根据 `v14C_entry_feature_need_list.csv` 提示，必须引入盘前/竞价级别的短期微观结构特征过滤（如竞价委买比率、主力大单净流入、量价乖离率限制等），大幅砍掉那些容易导致“日内跳水、次日快亏”的弱势标的。
2. **修改或废除现行晋级规则**:
   既然统计表明“晋级后收益为负”，应考虑缩短卫星转核心的持仓周期，或增加极其严苛的量价异动放量确认条件，否则应直接执行“卫星获利即止盈”而不进行晋级。
3. **平滑利润分布**:
   引入强制仓位分散或单笔利润 Cap 控制测试，看在削减 Top 3 暴利标的后，能否维持基础的正期望。如果剔除 Top 3 变负，说明底层Alpha失效。
