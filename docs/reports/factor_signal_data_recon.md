**日志确实记录了完整的入池信号层(2,067 笔,2023–2026 全覆盖),足够做信号层因子验证;但有三个硬约束必须先知道:**

## 1. 日志里有没有入池层候选信号?字段是什么?

**有。** 入池信号 = `WATCH_POOL_ADD` 记录(deep_water 候选未被买成核心仓 → 进观察池)。每条字段:

| 字段 | 示例 | 含义 |
|---|---|---|
| `date` | 2023-01-03 | 入池日 |
| `stock` / `name` | 002251.XSHE / … | 标的 |
| `signal_date` | 2023-01-03 | 信号日 |
| `signal_price` | 7.060 | 信号价(因子前向收益的基准价) |
| `signal_rank` | 0 | 信号排名 |
| `signal_score` | 0.7041 | **信号分(可做因子值)** |
| `signal_entry_type` | deep_water | 信号类型 |
| `reason` | core_candidate_not_bought | 入池原因 |

**配套的信号生命周期事件(都带 signal_price,可追踪同一信号):**
- `SHADOW_CONFIRM_CHECK`(2,834 笔):T+1/T+2/T+3 确认检查,**带 `current_price` / `ret_from_signal` / `day_ret` / `days_after_signal`** → 这是日志里**唯一的信号层前向收益来源**(但最多到 T+3)。
- `WATCH_POOL_EXPIRE`(1,642 笔):到期未买出池。
- `WATCH_POOL_REMOVE`(355 笔):买入/拉黑等移出。
- 上游候选池:`BIGMEAT_POOL_TOP`(2,495)、`BIGMEAT_POOL`(836)带 score/tpl/open_ratio 等。

成交层字段:`ENTRY_FEATURE_LOG`(235,带 entry_score 等入场特征)、`EXIT_OUTCOME_LOG`(233,带 pnl_pct/exit_reason)、`TRADE_CLOSE`(233,带 realized_pnl)。

## 4. 粗算:信号层按年的"信号后前向收益",是不是也只有 26 正?

**不是。粗算下,信号层 4 年全负,2026 也负。** 用 `SHADOW_CONFIRM_CHECK.ret_from_signal`(= current/signal_price − 1)按确认年聚合:

| 年 | 信号层 CONFIRM 均值(全部 T1-3) | 信号层 CONFIRM 均值(仅 T+3) | 成交层 EXIT 均值 pnl% | 成交层 EXIT 胜率 |
|---|---|---|---|---|
| 2023 | **−2.09%** | −3.08% | −3.26% | 5.7% |
| 2024 | **−2.06%** | −2.63% | +1.28% | 25.5% |
| 2025 | **−1.63%** | −2.09% | −1.30% | 15.2% |
| 2026 | **−1.87%** | −2.40% | +7.36% | 48.6% |

**两个层次要分开看:**
- **信号层(原始 deep_water 入池信号)**:信号后 1~3 日平均收益**每年都是负的**(−1.6% ~ −2.1%;只看 T+3 是 −2.1% ~ −3.1%)。**包括 2026。** 即原始信号短期是**均值回落**的(deep_water 本就是弱势/超跌票),不具备正向前向预测力。
- **成交层(被确认买入的子集)**:实现收益 2024 略正、**2026 显著正(+7.36%、胜率 48.6%)**,2023/2025 负。**2026 的强势出现在成交层,不在信号层。**

**含义**:组合层"只有 26 正"不是因为信号在 26 年才有 alpha,而是因为**确认过滤 + 入场时机 + 出场风控**在 26 年那 38 笔上奏效。把这点放到因子验证前很关键——**如果直接验证原始 signal_score 的前向 IC,大概率四年都接近 0 或负**,真正要验证的是"确认链 + 出场"这层,而不是裸信号。

> 注:成交层 EXIT 均值 pnl% 是逐笔等权,**不等于组合收益**(组合受仓位权重 + big_meat 10/20 大肉单主导)。所以"2024 逐笔 +1.28%"与"组合 24 年负"不矛盾。

## 5. 诚实评估:这份数据能否支撑用户要的多层因子验证(IS/OOS + 滚动 + 年度稳定 + regime)?

**部分能,但要分层看,且必须配聚宽取价。**

### ✅ 能支撑的
- **信号层因子研究**:2,067 笔入池信号,跨 2023–2026 全程,每年 400~700 笔,带 `signal_score`/`signal_rank`/`signal_price`/`signal_date` + 入场特征。**这是一份真正的多年信号面板**,支持:
  - IS/OOS 划分(如 23–24 IS / 25–26 OOS)——信号层样本够。
  - 滚动窗口、年度稳定性——信号层每年几百笔可算。
  - 前提:**去聚宽对这 2067 个 (stock, signal_date, signal_price) 取 T+1..T+10 前向价**,补出日志没有的 T+5/T+10。日志只给到 T+3。

### ⚠️ 受限 / 不能硬撑的
- **T+5/T+10 前向收益日志里没有**——watch 有效期 3 天,`ret_from_signal` 最多到 T+3。要 T+5 必须 `get_price`(沿用 counterfactual 脚本那套防未来函数取价铁律)。**纯靠日志做不出 T+5 因子 IC。**
- **成交层实现收益验证样本太薄**:235 笔总量,26 年仅 38 笔。在成交层做 IS/OOS + 滚动 + regime 的"实现 pnl"稳定性,**OOS 年 38 笔统计噪声极大**,只能当**佐证**,不能当主结论。
- **regime 分析只能做粗的**:日志是单策略的一条实现路径,不是横截面因子面板。按年/按市场状态分桶可做,但**精细 regime(波动率/广度分层)需要额外行情数据**,日志不足。
- **信号本身可能没有可验证的正 alpha**(见 §4)——验证前要有心理准备:裸 signal_score 的前向 IC 很可能四年都弱。真正值得验证的对象是"确认链 + 出场"这一层,而那一层就回到了 235 笔的薄样本问题。

### 一句话建议
- **做信号层因子验证可行**,但**必须先去聚宽给 2067 笔信号补 T+1..T+10 前向价**(日志只到 T+3);信号层样本够撑 IS/OOS + 滚动 + 年度。
- **成交层实现收益**只能当**辅证**(235 笔太少),不要在它上面下 regime/OOS 强结论。
- **先验证裸 signal_score 的前向 IC**(便宜),若四年都≈0/负(§4 已强烈提示),则因子验证的重心应转向"确认过滤 + 出场规则"的增量贡献,而不是继续打磨入场信号。
