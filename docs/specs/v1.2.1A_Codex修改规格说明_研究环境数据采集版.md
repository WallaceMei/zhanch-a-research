# v1.2.1A Codex 修改规格说明：最小数据采集版 + 聚宽研究环境分析准备

> 文件用途：给 Codex 读取的修改规格说明。
> 目标：把原 v1.2.1 的复杂影子逻辑拆开，策略端只做最小数据采集；规则扫描放到聚宽研究环境。

## 5. 聚宽研究环境分析脚本

请新增一个独立研究脚本文件：

```text
research_analyze_exit_add_rules.py
```

用途：

```text
在聚宽研究环境中运行。
读取回测导出的日志文本或复制粘贴日志文件。
解析 HOLD_SNAPSHOT / EXIT_EVENT / ADD_CANDIDATE_SNAPSHOT / TRADE_ANALYTICS。
离线扫描浮盈保护和提前加仓规则。
```

要求：

```text
这是研究环境脚本，不在策略回测中运行。
不要 import 到 战车A龙头3.py。
```

### 5.1 脚本功能

脚本至少包含：

```text
parse_log_lines
parse_key_value_log
load_log_file
build_hold_snapshot_df
build_trade_analytics_df
scan_float_profit_protection
scan_tail_add_rules
summarize_scan_results
```

### 5.2 浮盈保护扫描

扫描规则：

```text
rule_fp_15_5:
max_floating_pnl >= 15%
floating_pnl_drawdown >= 5%

rule_fp_20_7:
max_floating_pnl >= 20%
floating_pnl_drawdown >= 7%

rule_fp_30_10:
max_floating_pnl >= 30%
floating_pnl_drawdown >= 10%
```

输出：

```text
rule
trigger_count
stock_count
avg_trigger_pnl
avg_max_pnl
avg_drawdown_at_trigger
avg_final_trade_ret
better_than_actual_count
worse_than_actual_count
```

说明：

```text
初版只做近似分析：
如果影子信号早于真实退出，则比较 trigger_pnl 与 final trade_ret。
不要声称能完全替代回测。
```

### 5.3 提前尾盘加仓扫描

扫描规则：

```text
rule_add_5_5_v1:
hold_days >= 1
current_pnl >= 5%
day_ret >= 5%
volume_ratio_vs_prev >= 1.0

rule_add_8_5_v12:
hold_days >= 1
current_pnl >= 8%
day_ret >= 5%
volume_ratio_vs_prev >= 1.2

rule_add_10_5_high:
hold_days >= 1
current_pnl >= 10%
day_ret >= 5%
volume_ratio_vs_prev >= 1.0
close_to_day_high >= 0.97
```

输出：

```text
rule
trigger_count
stock_count
avg_trigger_pnl
avg_day_ret
avg_volume_ratio
limit_up_count
actual_add_overlap_count
avg_final_trade_ret
```
