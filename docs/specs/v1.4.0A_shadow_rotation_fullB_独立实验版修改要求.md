## 1. 实验背景

v1.4.0 影子轮动研究已在聚宽研究环境跑通，并启用 high_limit 涨停不可买过滤。

研究结果：

```text
candidates = 3003
watch = 615
confirmed = 243
sim_trades = 243
high_limit_available = 1
limit_up_filtered = 206
```

主要结论：

1. 候选池影子轮动有研究价值。
2. 涨停不可买过滤必须启用。
3. Rule D + deep_water 明显优于 trend_core。
4. trend_core 第一版不要进入真实策略。
5. day1/day2-3 样本都偏少，第一版不要限制确认天数，只允许 1-3 日内确认。
6. 满仓复利方向下，Full-B 更适合作为主实验版：
   - 核心仓 70%
   - 卫星仓 15% × 2
   - 总仓 100%
7. Full-C 收益最高但偏激进，第一版只作为后续对照，不作为主版本。
8. risk_off 缩仓研究未完成，因为日志缺少可用市场状态字段。第一版不要新造复杂大盘缩仓模型，只复用原策略已有风控/暂停逻辑。

## 3. 仓位结构

新增参数：

```python
g.shadow_rotation_enabled = True

g.core_slots = 2
g.core_target_total_ratio = 0.70
g.core_slot_ratio = 0.35

g.shadow_satellite_slots = 2
```

解释：

```text

```

## 5. WATCH_POOL 逻辑

新增 WATCH_POOL，只跟踪未买入的 deep_water 候选。

候选来源：

```text
优先复用原策略里 BIGMEAT_POOL_TOP / deep_water 候选生成逻辑
```

当日候选如果满足：

```text
signal_entry_type == deep_water
当日没有被核心仓买入
当前没有持仓
非 ST
非停牌
非退市
非涨停不可买
非黑名单 / 原策略排除池
```

则加入 WATCH_POOL。

WATCH_POOL 字段至少包括：

```text
stock
name
signal_date
signal_price
signal_rank
signal_score
signal_source
signal_entry_type
expire_date 或 expire_days = 3
watch_reason
```

注意：

```text
为避免未来函数，signal_price 应在收盘后或尾盘可确认时记录，不要在早盘用当日收盘价。
如果策略在 15:05 / 收盘后有任务，可以在收盘后记录 signal_price。
如果没有收盘后任务，就在尾盘接近收盘时用当前价记录。
不能用未来不可见的当日完整收盘价。
```

## 7. 卫星仓确认买入规则

只允许 WATCH_POOL 中的 deep_water 标的触发卫星买入。

确认周期：

```text
signal_date 后 1-3 个交易日内
days_after_signal 必须在 [1, 2, 3]
```

确认时间：

```text
优先在尾盘确认，例如 14:40-14:50
不要早盘确认，避免盘中冲高回落
```

Rule D + deep_water 条件：

```text
ret_from_signal >= 5%
day_ret >= 5%
1.0 <= volume_ratio_vs_prev <= 2.0
ma5_distance <= 10%
close_to_day_high >= 0.97
signal_entry_type == deep_water
非涨停不可买
非停牌
非 ST
未持仓
未触发原策略暂停买入状态
```

字段计算：

```text
ret_from_signal = 当前价 / signal_price - 1
day_ret = 当前价 / 昨日收盘价 - 1
volume_ratio_vs_prev = 今日截至当前成交量 / 昨日成交量
ma5_distance = 当前价 / MA5 - 1
close_to_day_high = 当前价 / 今日截至当前最高价
```

注意：

```text
所有字段必须用当前时点可见数据，禁止未来函数。
如果无法安全获取今日截至当前成交量或今日截至当前最高价，不要用未来全日数据硬算。
如果某字段取不到，记录 SHADOW_CONFIRM_SKIP，并跳过该股票。
优先复用原策略已有安全行情函数。
high_limit 使用 get_current_data()[stock].high_limit 或原策略已有涨停价函数。
如果当前价 >= high_limit * 0.999，视为涨停不可买，跳过。
```

新增日志：

```text

SHADOW_CONFIRM_PASS
SHADOW_CONFIRM_SKIP
```

日志字段：

```text

```

## 8. 卫星仓买入逻辑

如果卫星仓未满：

```text
买入该标的作为 satellite 仓
目标仓位 = 15%
不超过总仓位 100%
如果现金不足，按可用现金下单，不融资、不加杠杆
```

如果卫星仓已满：

```text
只允许替换最弱卫星仓
不替换核心仓
```

最弱卫星仓判断：

```text
当前亏损仓位优先
跌破 MA5 的仓位优先
持有超过 3 日仍无盈利的仓位优先
当前盈利最小的卫星仓优先
```

只有新候选明显更强时才替换。

新候选强度：

```text
candidate_strength =
ret_from_signal
+ day_ret
+ volume_ratio_vs_prev * 2
+ signal_score * 10
```

当前弱仓评分：

```text
current_score =
当前盈亏
- 跌破 MA5 惩罚
- 持有超过 3 日仍无盈利惩罚
```

只有：

```text
candidate_strength > current_score + 5
```

才允许替换。

新增日志：

```text
SHADOW_REPLACE_DECISION
SHADOW_REPLACE_SKIP
SHADOW_REPLACE_EXECUTE
```

要求：

```text
不替换核心仓
不替换盈利最多卫星仓
不因为新票信号而强行卖出核心持仓
```

## 9. 卫星仓退出逻辑

卫星仓独立退出，不影响核心仓。

退出条件：

```text
1. 最长持有 5 个交易日，到期退出
2. 卫星仓亏损 <= -6%，止损退出
3. 当前价跌破 MA5，且 pnl <= 0，退出
4. 持有超过 3 日，pnl <= 0，退出
5. 原策略进入极端风险 / 暂停新开仓状态时，不新增卫星仓；已有卫星仓按退出规则处理，不强行全卖，除非原策略已有全局清仓逻辑
```

新增日志：

```text
SHADOW_EXIT_SIGNAL
SHADOW_EXIT_SUBMIT
SHADOW_EXIT_CONFIRMED
```

日志字段：

```text

stock
name
entry_date
hold_days
entry_price
current_price
pnl
ma5
below_ma5
reason
```
