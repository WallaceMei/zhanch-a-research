## 0.1 术语定义(全文照此,避免天数/口径歧义)

```text
day0 = 买入当日(T日),记为第1个持仓交易日。
day1 = 买入后第一个可卖交易日(T+1)。
所有卖出规则从 day1 起生效;day0 仅记录 day0_untradable_risk,不成交。
hold_days 从 day0 算起。20天天花板 = 持仓满第20个交易日。

触发与成交分离(全文统一):
- 触发判定:用 minute_close 与触发线比较(硬止损/MA5/移动止盈同此)。
- 成交价格:触发确认后,"下一个有效分钟bar的 open" × (1 ± slippage)。
- 开盘跳空特例:若当日9:31第一根bar的close已破触发线,该bar视为触发,
  成交用再下一根bar的open;若当根跌停无量,记 sell_blocked,顺延。
```

### 3.2 机械进场闸

观察窗口:9:30–10:30

条件1:当前价站上 VWAP → `minute_close >= VWAP`

条件2:回踩不有效跌破 VWAP(默认口径):
```text
价格触及/接近VWAP后,15分钟内重新站回VWAP上方 视为回踩有效;
或回踩最低价 >= VWAP × (1 - 0.5%) 视为未有效跌破。
```

信号与成交:
```text
signal_time = 第一次同时满足 VWAP站稳+回踩不破 的分钟bar结束时间。
buy_time = signal_time 的下一根有效分钟bar。
buy_price = buy_time 的 open × (1 + buy_slippage)。
无分钟open则用下一分钟close替代,记 price_proxy_flag。
简化口径:统一10:30判断,10:31 open买入。
禁止:T日open;禁止 signal_time 之前的任何价格。
买入截止:10:45。10:45前无法成交则放弃该票。
```

成交价格:触发后下一根有效bar的 open × (1 - sell_slippage)。
开盘跳空:若9:31首根bar close已破,该bar触发,成交用再下一根bar open;

### 3.5 出场层

原则:亏的快走(守T+1),赚的让它跑(移动止盈锁利润),不死扛(20天天花板兜底),机械规则优先于AI建议。所有卖出从 day1 生效,day0 不卖。

**3.5.1 硬止损 -7%**(见 3.4,优先级最高)

**3.5.2 MA5 破位止损**
```text
MA5_prev = 截至前一交易日收盘的最近5个有效交易日 close 均值。
当天盘中所有MA5判断固定用 MA5_prev,禁用当日收盘后MA5。

口径A(连续检查点跌破):
- 检查频率:每5分钟一次。
- 触发:连续 N 个检查点 minute_close < MA5_prev,默认 N=3。
- 成交:下一根有效bar open卖出。

日内收回豁免:盘中破MA5但能拉回站上 → 继续持有。

尾盘确认:14:50时 minute_close < MA5_prev 且未卖出 → 14:50后下一根bar卖出。
  仅日线回测则用 close < MA5_prev,标 daily_proxy。
```

**3.5.3 两段式移动止盈**(配法丙)
```text
peak_price = 买入后截至当前已完成分钟bar的最高 minute_close。
peak_return = peak_price / buy_price - 1。
current_drawdown = minute_close / peak_price - 1。

默认参数:
  第一段:peak_return < +25%,从峰值回撤15%卖出(撒开跑)。
  第二段:peak_return >= +25%,分级收紧(锁利润):
    peak_return >= +25%,回撤12%卖出;
    peak_return >= +40%,回撤10%卖出;
    peak_return >= +60%,回撤8%卖出。

触发:current_drawdown <= -对应阈值 → 下一根bar open卖出。
跌停/停牌无法卖 → 记 sell_blocked,继续尝试。
辅助观察口径:peak_price_high = 最高 minute_high(仅观察,主报告以minute_close为准)。
```

**3.5.4 20天时间天花板**
```text
hold_days 从 day0 算起(day0为第1个持仓交易日)。
满第20个持仓交易日仍未触发其他规则 → 第20日14:50后下一根bar卖出。
仅日线则用第20日close,标 daily_proxy。
7-10天非硬规则,是 MA5+移动止盈 自然淘汰的平均落点。
```

**3.5.5 卖出优先级**
```text
1. 硬止损-7%  2. MA5破位  3. 移动止盈  4. 20天天花板
当天卖不出:保留最高优先级 pending_exit_reason,下一bar/下一日继续尝试;
不得因卖不出而重置移动止盈峰值或取消止损状态。
```
