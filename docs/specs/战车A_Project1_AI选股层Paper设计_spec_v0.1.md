# 战车A Project 1 — AI 选股层 Paper Trading 设计 spec v0.1

> 承接 Phase A(出场引擎已验证)。本阶段验证 Project 1 唯一未验证的一层:AI 选股(胜率端)。
> 核心性质:AI 选股不可历史回测,只能 forward paper 验证。本 spec 是"多策略对照实验 + 只读看板"。
> 三方协作:Wallace=owner / Claude=规划翻译 / CC=执行。用中文。

---

## 0. 本阶段要回答的唯一问题

**AI 从战车A候选池里选股,到底比"不选"(全进)和"瞎选"(随机)更好吗?**

- 不是问"AI选的票赚不赚钱"(赚不赚主要看行情regime,不是AI能力)。
- 是问"同一批候选池、同一进场闸、同一出场引擎下,AI选股 vs 随机选 vs 全进,谁的相对表现更好"。
- **命门:验收看相对表现(AI vs 对照),不看AI绝对收益。行情好坏对三组同时作用,组间差异才是AI选股能力的真信号。**

## 1. 系统流程(三组唯一变量=选股方式)

```
战车A候选池 top12(每日,repro_core 零改动)
        │
        ▼
 ┌──────────────┬──────────────┬──────────────┐
 │ AI 选股组     │ 随机选组      │ 机械全进组     │  ← 唯一变量在这一层
 │ AI盘前选N只   │ 盘前随机选N只  │ 全部过闸票     │
 └──────┬───────┴──────┬───────┴──────┬───────┘
        ▼              ▼              ▼
   各组选中的票 → 进入"实时进场监测池"
        │
        ▼
 实时进场闸(9:30-10:30,QMT实时数据)  ← 三组完全一致
 每只票实时监测:VWAP站稳 + 回踩不破,满足的那一刻按当时价买入
        │
        ▼
 机械出场引擎(三组完全一致)
 硬止损-7% / MA5破位 / 移动止盈(收紧dd10附近) / 20天天花板
        │
        ▼
 只读对照看板(三组实时PK)
```

**关键:进场闸和出场引擎三组一模一样,唯一差别是"哪些票进了监测池"。这样对照公平,能干净分离出AI选股的价值。**

## 2. 各组决策逻辑

### 2.1 AI 选股组(本阶段核心)
- **时点**:盘前(9:30开盘前,或9:25竞价后),一天决策一次。
- **输入**:当日 top12 候选池,每只票喂给AI的字段(见 §3)。
- **任务**:从 top12 里选出 N 只"最值得进入监测池等进场"的票。
- **输出**:选中的N只 + 每只信心分 + 选择理由(结构化JSON,见 §3)。
- **AI看的是**:基本面 + 题材/概念 + 昨日盘面 + 竞价表现。**不看当天分时**(当天分时由机械进场闸负责确认)。
- **分工**:AI管"选哪些票值得等",机械进场闸管"等到确认点才买"。

### 2.2 随机选组(基准1:AI有没有信息)
- 盘前从当天 top12 里随机选 N 只(同N)。
- 随机种子固定可复现,但每天不同(避免选到同一批)。
- 意义:**AI跑不赢随机 = AI在瞎选,没有真信息**。

### 2.3 机械全进组(基准2:AI有没有超过闭眼全买)
- 当天 top12 全部进监测池(不选)。
- 就是 Phase A 那个 -90% 负基座。
- 意义:**AI跑不赢全进 = 选股是负价值**。

### 2.4 (可扩展)其他对照组
- 架构做成"选股器可插拔",每组是一个决策函数,看板自动加一条线。
- 未来可加:按dragon_score选topN / 不同N值 / 不同AI prompt版本 / AI+机械混合。
- **⚠️ 多重比较陷阱**:策略越多,越可能有某个碰巧这段最好(纯运气,像Phase A假平台)。
  判"AI有没有用"的核心对照,永远锁定 随机 + 全进 两个基准,不被"某策略这周最高"带偏。

## 3. AI 选股接口

### 3.1 输入(喂给AI的字段,盘前可得)
每只 top12 票:
```
- 代码 / 名称 / 所属行业板块
- 当前题材/概念标签(热点归属)
- 昨日:涨跌幅 / 是否涨停 / 封单强度 / 成交额 / 换手率
- 近期:近N日涨停次数 / 是否首板反包/高标 / 3日涨幅
- 竞价:今日竞价高开幅度 / 竞价量比(9:25后可得)
- 基本面摘要:市值 / 主营 / 最新公告或新闻要点(可选,若接新闻源)
- dragon_score(战车A打分,供AI参考,但AI不必须follow)
```
**红线:严禁给AI任何"未来信息"(当天开盘后走势/结果)。盘前决策只能用盘前可得字段。**

### 3.2 输出(结构化JSON)
```json
{
  "date": "2026-07-XX",
  "decision_time": "09:20:00",
  "model_version": "deepseek-vX",
  "picks": [
    {"code":"XXXXXX.XSHE","name":"示例","confidence":0.78,
     "weight_suggest":0.35,"reason":"题材主线+昨日首板反包+竞价温和"}
  ],
  "rejected": [{"code":"YYYYYY.XSHE","reason":"高位接力风险大"}],
  "market_note": "今日情绪偏弱,建议少选"
}
```

### 3.3 仓位分配(你定的"按仓位管理分配")
- AI输出 weight_suggest,结合信心分,按你的仓位管理规则分配到选中的N只。
- 具体分配规则(沿用战车A/V3.5仓位逻辑 or 新定),paper阶段先用简单版:
  等权 or 按信心分加权,待你定。
- 三组仓位口径要一致(否则对照不公平):建议三组都用"选中票等权"或"同一套仓位规则",
  唯一变量保持在选股,不在仓位。**仓位口径你拍。**

### 3.4 异常处理
- AI超时/无返回/JSON错/信心分异常 → 当日AI组**空仓不参与**(记录当日无决策),
  不fallback成全进或随机(否则污染对照)。
- 随机组/全进组正常跑(它们不依赖AI)。

## 4. 实时进场监测(三组共用,QMT实时数据)

- 9:30开盘起,对"三组监测池里的所有票"(去重)实时监测。
- 每只票实时算 VWAP,判定:当前价站上VWAP + 回踩不有效跌破(口径同Phase A:触及后N分钟拉回 / 回踩最低≥VWAP×99.5%,待调)。
- 满足的那一刻 → 记录该票"进场时刻 + 进场价",对"监测池里包含它的组"记为已买入。
- 10:45 截止,未满足的票当日放弃。
- **同一只票若AI组和全进组都选了,它进场时刻/价格相同,只是归属不同组的持仓**(对照公平)。

**技术**:QMT/xtdata 实时行情,只在 9:30-10:45 时段实时;之后持仓盈亏可低频更新/盘后结算。

## 5. 出场引擎(三组完全一致,沿用Phase A)
- 硬止损 -7% / MA5破位(N=3,日内收回豁免)/ 移动止盈(用Phase A硬发现:收紧dd10附近)/ 20天天花板。
- 均 day1 生效。
- 三组一模一样,不是本阶段变量。

## 6. 只读对照看板(复用web层)

### 6.1 核心视图
1. **三组净值对比曲线**(同图三条线,一眼看谁跑赢)—— 验收核心视图
2. **相对表现**:AI减全进、AI减随机 的差值曲线(把regime消掉,看AI真alpha)
3. **每日决策明细**:各组今天选了哪些票(AI组带信心分+理由)、各票进场时刻/价
4. **累计统计表**:各组 胜率/盈亏比/大肉捕获/最大回撤/累计收益/样本笔数
5. **AI决策留痕**:AI每次输入快照+输出JSON+时间戳(可追溯,复盘AI判断对错)

### 6.2 设计要求
- **只读**:纯展示,不下真单、不驱动交易(paper阶段安全边界)。
- **策略可扩展**:每组一条可插拔决策器,加策略自动多一条线。
- **复用**:quant_platform 现有 web 层(FastAPI+Jinja2)或数据中台看板架构。
- **成交/盈亏更新**:进场时刻实时抓取,持仓盈亏盘中低频刷新 or 盘后结算。

## 7. 验证标准(命门,先定后跑,不许跑完再定)

### 7.1 第1周:管线验收(不看输赢)
- 三组正常运行、AI决策+进场时刻+成交+盈亏 全部如实落盘、无bug。
- 跑通即过。这周**只验系统跑起来了没,不判AI价值**。

### 7.2 持续跑(4-8周,攒够50-100个进场决策):价值验收
- **AI组同时跑赢 全进 和 随机** → AI选股有正价值,可考虑上真钱。
- **AI跑不赢随机** → AI在瞎选,放弃这个AI选股方向。
- **AI赢全进但输随机** → AI没真信息,只是沾了"少选票"的光,存疑,不上真钱。
- **稳定性**:不是某一周赢就算,要多数周稳定赢(逐周看,防单周运气)。

### 7.3 诚实纪律(承接Phase A教训)
- 绝不看绝对收益判AI(regime会骗你,像2026H1那个+25%)。
- 绝不因某周AI高就上真钱(单周是运气)。
- 加策略后警惕多重比较(总有一个碰巧最好)。
- paper不能加速,真实时间攒样本,急不来。

## 9. 已定配置(Wallace 拍板,2026-06-30)
1. **N选几只**:AI从top12选 **3只**(呼应实盘MAX_POS=3)。
2. **仓位口径(三组一致)**:选中票每只 **25%**,总持仓 **75%**,留 **25%现金**。
   - 三组同一套规则,保持对照纯净(唯一变量=选股方式)。
   - 全进组:过闸票按25%上限依次买到满(75%),不超配。
3. **AI模型**:纯 **MiniMax**。第一版只用MiniMax单独选股;
   Wallace的复盘skill和trading agent **后续再逐个加**(先验单AI,再看每个辅助有没有提升)。
4. **进场口径**:**Phase A默认**(观察9:30-10:45,VWAP站稳;回踩15分钟内拉回 或 回踩最低≥VWAP×99.5%)。
   注:无"最优口径"(Phase B未跑),paper沿用默认;跑一段发现进场闸有问题再单独做Phase B。
5. **多agent**:**先单AI**跑通。A打分/B分析/C综合的多agent架构,验证单AI有价值后再加。
6. **web**:复用现有 **quant_platform**(FastAPI+Jinja2),不新建。
