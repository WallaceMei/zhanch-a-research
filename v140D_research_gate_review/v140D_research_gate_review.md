# v1.4.0D Observer 策略全区间研究级准入评审报告

## 1. 准入评审概述与版本关系确认

本评审报告基于 `v1.4.0D_observer` 的 smoke test 机制验证结果，结合 `v1.4.0C` 研究基线与 `D3_no_promotion_take_profit_plus_cap_fixed`（简称 D3）反事实重放（replay）候选数据，进行全面的研究级准入分析。

### 1.1 版本背景与逻辑定位
- **v1.4.0C（基线）**：为当前的研究基线，主要验证了“核心+单卫星”角色轮动架构（Core-Satellite Rotation），其主要数据体现在 `role_rotation_result_bundle V140C` 中。
- **D3 Replay 候选（反事实重放）**：通过对历史成交事件（BUY/SELL/ROLE_PROMOTION_EXECUTE）的反事实重放进行回溯，是当前在非交易机制约束下表现最优的理论版本（Sharpe 2.1251，年化收益 78.84%）。**D3 并非真实的交易策略代码，仅为回测重放逻辑。**
- **v1.4.0D Observer（观察版策略）**：是试图将 D3 理论版本“策略化”的落地尝试。由于在策略代码中无法直接获取 D3 重放的“未来晋级事件”，因此引入了 `no_promotion` 机制作为 **observer proxy（观察者代理条件）**，以 `pnl >= 0.03 and not below_ma5` 作为代替条件。
- **特别声明**：当前 `no_promotion` 只是近似代理，并不是 D3 replay strict 的等价实现。

## 2. 容量限制机制评审 (`cap_fixed`)

基于 `v140D_smoke_test_audit` 中的 `cap_fixed_events.csv` 和 `cap_post_buy_check.csv`，对策略化版本中的容量调控机制进行核查：

### 2.1 统计结果
- **CAP_FIXED_BUY_OK（买入成功确认）**：44 次
- **CAP_FIXED_TRIM（限额缩单截断）**：14 次
- **CAP_FIXED_SKIP_NO_CAPACITY（额度耗尽跳过）**：7 次
- **最大 Post-Buy 总仓位占比**：**74.88%**，严格处于 75% 限制之下。

### 2.2 安全机制确认
- **买入后超限**：**不存在**任何在 `BUY_OK` 之后总仓位占比超过 75% 的情况。
- **市值重估超限（Mark-to-Market）**：存在 **4 次** 在触发 `TRIM/SKIP` 时，`current_total_ratio` 已经超过 75% 的情况（最高达 76.03%）。此类事件已被正确标记为 `mark_to_market_or_pre_existing`，这是由于既有持仓市值上涨或资金分母变动引起的被动超限，策略代码在此时点正确执行了“不予新买”或“截断至0”的安全防护，未产生主动买入越界。
- **尾盘加仓保护**：6 次 `LIVERMORE_ADD_SUBMIT` 在相同分钟均被 `CAP_FIXED` 前置模块捕获并进行容量校准，**0 绕过**，证明加仓路径安全修复成功。

## 4. 快速止损与大肉截断评审 (`fast_loss / big_meat`)

基于 `exit_outcome_events.csv` 和 `entry_exit_matched.csv`，分析止损控制与获利留存表现：

### 4.1 核心统计
- **总配对交易笔数**：37 笔
- **快速止损触发 (fast_loss_count)**：**17 笔**（占总交易的 **45.95%**）。说明快速止损机制高度活跃，能够有效截断单笔下行风险。
- **大肉交易 10% 留存 (big_meat_10_count)**：**6 笔**（占比 16.22%）。
- **超级大肉 20% 留存 (super_meat_20_count)**：**3 笔**（占比 8.11%）。

### 4.2 阻断止盈对大肉截断的影响分析
- 从第 3 节的 7 笔阻断平仓明细可见，这 7 笔交易的平均持股仅有 **1.71 天**，收益率被锁定在 **4.68% ~ 9.75%** 之间（均未达到 10%）。
- **潜在截断迹象**：由于 observer proxy 在卫星仓位浮盈达到 3% 且未破 MA5 时即采取“强行拦截并止盈”的策略，直接导致这部分原本强势的票（如新金路、江特电机、深科技等）在极早期便被兑现，彻底剥夺了它们在角色轮动中升级为 Core 并成长为“10% 大肉”或“20% 超级大肉”的可能性。
- 这是典型的**以牺牲上行爆发力换取高胜率/低持仓期**的做法。虽然锁定了 7 笔利润，但对大周期复利而言，这构成了明显的利润截断风险。

## 5. 盈利集中度评审

策略总体毛盈利与毛亏损的分布极度不均，表现出明显的长尾依赖性：

### 5.1 盈利集中度统计
- **净利润 (Net PnL)**：**+59,822.00**
- **总毛盈利 (Gross Profit)**：**+88,006.00**
- **总毛亏损 (Gross Loss)**：**-28,184.00**
- **最大单笔盈利**：**+22,804.00** (`603629` 利通电子，收益率 39.89%)
- **最大单笔亏损**：**-2,450.00** (`002980` 华盛昌，收益率 -6.28%)

### 5.2 Top N 贡献占比
- **Top 1 盈利贡献**：**22,804.00**（占总毛利的 **25.91%**，占净利润的 **38.12%**）
- **Top 3 盈利贡献**：**52,735.00**（占总毛利的 **59.92%**，占净利润的 **88.15%**）
- **Top 5 盈利贡献**：**70,743.00**（占总毛利的 **80.38%**，占净利润的 **118.26%**）

### 5.3 集中度诊断结论
- **极度依赖少数极优交易**：前 3 笔最大盈利贡献了净利润 of 88.15%，前 5 笔交易更是合贡献了净利润的 118.26%（其余 32 笔交易整体净亏损）。
- 一旦市场环境变化导致这两三笔“神单”未能成行，或者大肉因 proxy 阻断被提前截断，该策略的整体夏普和收益率将立刻发生实质性逆转。存在较大的**过拟合与幸运偏差**风险。

## 6. 样本外（OOS）稳定性评审

- **严重退化**：在进入严格样本外（OOS）后，胜率暴跌至 **20.00%**，区间净收益直接转负为 **-0.49%**，夏普比率更是近乎归零（**0.0527**）。

- **结论**：OOS 区间的表现与 Train 区间产生极强烈的背离，说明当前 observer proxy 的机制在推广性上非常薄弱，在 OOS 期处于失效状态。

## 8. 准入决策矩阵

我们综合考量下述八个维度，对 `v1.4.0D_observer` 进行等级评定：

| 评估维度 | 指标现状 | 决策影响 | 评级 |
| :--- | :--- | :--- | :---: |
| **1. 机制验证** | `cap_fixed` 修复成功，`promotion_block` 闭环正常 | 逻辑执行符合设计，消除 smoke test blocker | **PASS** |
| **2. 样本容量** | 总交易 37 笔，OOS 仅 15 笔 | 样本量过低，统计置信度不足 | **WARNING** |
| **3. 止损保护** | 快速止损占比 45.95% | 限制了单单下行风险，但加剧了磨损 | **PASS** |
| **4. 盈利集中度** | Top 3 交易占净利 88.15% | 极度不健康，抗风险能力极低 | **FAIL** |
| **5. 大肉留存度** | Proxy 阻断了潜在晋级，OOS 期 0 大肉 | 机制存在利润截断硬伤 | **FAIL** |
| **6. OOS 稳定性** | OOS Sharpe 0.0527，净值收益率 -0.49% | 样本外发生严重衰退 | **FAIL** |
| **7. 成本敏感性** | 0.3% 摩擦增量下利润衰减 12.93% | 抗磨损能力出色 | **PASS** |
| **8. 等价性差距** | 阻断为止盈 proxy，非 D3 真实晋级逻辑 | 逻辑不一致，observer 无法证明 D3 优势 | **WARNING** |

### 最终决策：
**B. 继续保留 v1.4.0D_observer，补充研究**

### 决策理由：
虽然 `cap_fixed` 与 `promotion_block` 的底层代码逻辑在 smoke test 中顺利通过了机制验证（排除错误后确认无逻辑死锁、无越界主动买入、尾盘无加仓旁路），但我们**绝不能**因为其模拟期间赚取了 71.59% 的账面高收益就盲目升级至 `v1.4.0E_candidate`。

因为：
1. **严重的 OOS 衰退**：在 4月中旬以后的样本外（OOS）测试中，夏普比率跌至 0.05，交易胜率仅 20.00%，未能维持住基线和 D3 Replay 的强劲表现，具有极高的过度拟合嫌疑。
2. **极端的利润集中度**：88% 的净收益集中于 3 笔交易，具有极大的偶发性。
3. **晋级等价性代偿**：当前的 `no_promotion_take_profit` 依然是个简化版的 proxy 条件，极易在大行情下“截断大肉”，造成策略上限的严重损失。

因此，本版本只能保留在观察状态，**绝对禁止进入小区间主线或实盘**。后续必须继续补充研究如何对齐严格的晋级反事实重放逻辑。
